# DesiBites - Food Delivery Application 🍽️

## Overview

DesiBites is a full-stack food delivery application developed using React.js and Spring Boot. The application allows users to browse food items, manage carts, place orders, and track order details.

## Features

### 👤 User Management
- User registration
- User login
- User authentication

### 🍔 Product Management
- View food products
- Add products
- Delete products
- Search and filter food items

### 🛒 Cart Management
- Add items to cart
- Remove items from cart
- Manage cart items

### 📦 Order Management
- Place orders
- View user orders
- Update order status
- Admin order management

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Java
- Spring Boot

- Spring Data JPA
